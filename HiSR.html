用於階層文本分類中對比學習的
新型負樣本生成方法

A Novel Negative Sample Generation Method for Contrastive Learning in Hierarchical Text Classification
Juncheng Zhou・Lijuan Zhang・Yachen He・Rongli Fan・Lei Zhang・Jian Wan
浙江科技大學／ByteDance Ltd.　｜　COLING 2025（第31屆國際計算語言學會議）第5645–5655頁

摘要

階層文本分類（Hierarchical Text Classification, HTC）是自然語言處理（NLP）中的一項重要任務。現有方法通常同時利用文本特徵與標籤的階層結構來對文本進行分類。然而，這些方法在面對彼此高度相似的細粒度標籤時，往往難以準確分類。與此同時，對比學習在強化細粒度標籤特徵與區分能力方面具有顯著優勢，但對比學習的效果高度依賴於負樣本的構造方式。本文設計了一種階層序列排序（Hierarchical Sequence Ranking, HiSR）方法，用於生成多樣化的負樣本，以最大化對比學習的效果，藉此提升模型區分細粒度標籤的能力，並改善模型在 HTC 任務上的表現。具體而言，我們依據標籤的階層結構，將整個標籤集合轉換為多條線性序列，並依其品質對這些序列進行排序；在模型訓練過程中，動態地從排序後的序列中挑選出最合適的負樣本。本方法已在三個公開資料集上進行測試，並在其中兩個資料集上達到了當前最優（SOTA）表現，證明了其有效性。

1　引言

階層文本分類旨在將文本劃分至一組由粗到細排列的結構化類別中，藉此捕捉語言的複雜性與多維性。由於學術文獻、法律文件、線上內容等各領域文本資料量龐大，HTC 的重要性日益凸顯。在 HTC 中，標籤之間的階層結構通常被建模為樹狀結構或有向無環圖（DAG），如圖1所示。

圖1說明：以《紐約時報》（NYT）資料集為例展示 HTC。標籤階層從上到下排列，粒度由粗到細——例如根節點下分為「新聞（News）」「專題（Features）」「分類廣告（Classifieds）」等粗粒度類別，再逐層細分至「銀行、金融與保險」「銷售與商業發展」等細粒度類別。圖中並標示出一段真實新聞文本及其對應的真實標籤路徑（Root → News → U.S. → Midwest 等）。

現有的 HTC 方法大致可分為局部方法（local approaches）與全局方法（global approaches）兩類。局部方法為階層中的每個節點分配一個獨立分類器，這會導致參數量龐大，並容易產生曝光偏差（exposure bias）。全局方法則使用單一分類器處理整個階層，參數量較少、效率較高，但這類方法難以應對 HTC 中「資料分佈不均衡」與「跨層級複雜依賴關係」所帶來的挑戰，導致模型對細粒度標籤的區分能力下降。

如圖1所示，粗粒度標籤（如「新聞」「專題」「分類廣告」）之間的差異，明顯大於細粒度標籤（如「銀行、金融與保險」和「銷售與商業發展」）之間的差異。因此，區分深層、細粒度的標籤對 HTC 的效能至關重要。對比學習已被證實能有效增強標籤特徵與標籤可區分性，但目前將 HTC 與對比學習結合的研究仍處於早期階段：既有研究主要著重於「從文本角度透過資料增強構造正樣本」，卻未能解決「區分相似細粒度標籤」這一核心挑戰。作者認為，解決此問題的關鍵在於結合複雜的階層結構來構造恰當的正、負樣本。

為此，本文提出 HiSR（階層序列排序）方法，從標籤角度生成更有效的負樣本，協助對比學習提升模型區分細粒度標籤的能力。其核心思路是：充分利用標籤系統的整體階層結構，並運用深度優先搜尋演算法（DFS）構造多條序列型負樣本，接著在模型訓練過程中動態選取最具挑戰性的負樣本組合，以確保負樣本的高品質與多樣性。這種有針對性的動態選擇機制，對於放大細粒度標籤之間的差異至關重要。

本文主要貢獻

  • 我們創新性地設計了一種負樣本生成策略 HiSR，為對比學習提供高品質的負樣本，解決了細粒度標籤難以區分的問題。
  • HiSR 將標籤建模為序列並依品質排序，為引入「負樣本–負樣本」比較提供了基礎；此外，訓練過程中採用動態選擇機制，為模型提供最合適的負樣本。
  • 實驗證明，本文所提方法在三個廣泛使用的公開資料集上均優於既有研究成果。程式碼已開源於 https://github.com/zjcjason/HiSR。

2　相關工作

2.1　階層文本分類

HTC 的主要挑戰包括：充分利用類別間的階層資訊、區分相似的細粒度標籤，以及處理資料不均衡問題。既有研究大致可分為局部方法與全局方法兩大類。

局部方法在階層中的每個節點或層級使用專門的分類器。例如有研究提出從父分類器向子分類器傳遞參數的策略以提升節點效率；也有研究提出結合局部與全局策略的混合方法以降低曝光偏差；還有研究透過參數共享機制處理類別分佈的偏斜問題；亦有研究利用 N-gram 詞元搭配圖卷積網路（GCN）與遞迴正則化來捕捉階層表示。這些方法反映了局部方法在 HTC 領域的演進歷程。

全局方法使用單一統一模型同時指派多個階層標籤，將整個階層整合進單一預測框架中。相關研究深入探討了連續層級之間（尤其是父子關係）的複雜關聯；後續研究進一步將焦點延伸至：先驗階層機率、標籤整體結構、資料不均衡、標籤與語意的對齊、對比學習在詞元表示中的應用等面向。其中，HJCL 建構了基於 HGCLR 的階層感知聯合監督式對比學習方法；HALB 則加入多標籤負向監督與非對稱損失函數。此外，亦有研究在提示調校（prompt-tuning）與多標籤遮罩語言模型方面取得進展，致力於形成對階層語意的連貫理解；也有研究致力於建構同時涵蓋局部與全局階層維度的共通表示。近期，NERHTC 則將 HTC 視為一項命名實體識別（NER）任務來處理。

綜上所述，HTC 領域面臨的挑戰在於：如何設計出能夠充分利用標籤間階層關係的演算法，以提升分類的準確度與效率。

2.2　對比學習

對比學習是機器學習與深度學習中廣泛使用的一項技術，旨在透過比較不同樣本來學習有利於下游任務的通用化表示。此方法的關鍵在於正、負樣本的構造。在 NLP 領域，構造這類樣本的標準方法包括：回譯（back-translation）、詞語與片段的刪除／重排／替換、對原始詞元進行隨機擾動等，這些方法主要用於生成正樣本。而納入負樣本則可進一步提升對比學習的效果——例如，有研究透過語意改變的詞語修改來引入擾動以生成負樣本；也有研究透過調整模型的嵌入層來生成對抗樣本。

然而，這些方法都是針對特定下游任務量身打造的正、負樣本生成方式。由於 HTC 具有複雜的階層結構，要生成同時符合「文本語意」與「階層結構」兩方面要求的正、負樣本極為困難。

3　方法論

本節聚焦於負樣本生成與對比學習模組，這是提升模型區分細粒度階層標籤能力的關鍵所在。此外，本節也將說明文本編碼器與結構編碼器，最後介紹整合各組成部分以優化模型整體效能的目標函數。圖2展示了本模型的整體架構。

圖2說明（整體架構）：文本先經 BERT 編碼為文本表示，同時標籤階層經結構編碼器（Structure Encoder，即階層 GCN）編碼；兩者輸入多標籤分類器產生 logits，用於計算分類損失（Classify loss）。另一方面，虛線框內展示 HiSR 的核心流程：對「標籤階層」進行遍歷（Ergodic）以 DFS 產生多條標籤序列，並與「真實標籤（Ground Truth）」比對計算 F1 分數；依 F1 分數分組（排除 F1=1 的正樣本）並取平均後挑選機率最高者作為當前回合的負樣本；真實標籤序列作為正樣本，連同挑出的負樣本一起送入「對比學習（Contrast Learning）」模組計算 HiSR 損失。

3.1　問題定義

在 HTC 任務中，目標是將一組文本集合 X = {x₁, x₂, …, xₙ}（n 為文本數量）映射到標籤子集 Yᵢ ⊆ Y，其中 Y = {y₁, y₂, …, yₙ} 為完整標籤集合。與傳統文本分類不同，HTC 任務的特點在於標籤間存在預先定義的階層關係 H，該關係可能表現為樹狀結構、有向無環圖（DAG），或其他複雜的階層形態。這種階層組織不僅反映了標籤間的語意關係，也對理解複雜的資訊內容具有重要作用。

3.2　文本編碼器

考量 HTC 的挑戰，本文選用 BERT 作為文本編碼器，因其能捕捉雙向語境，對語言有較全面的理解。BERT 先在大規模資料上進行預訓練，再針對特定任務進行微調，因此在各類 NLP 應用中表現優異。

設輸入文本為 x：

x = { [CLS], t₁, t₂, …, tn-1, [SEP] }　　（式1）

其中 [CLS] 與 [SEP] 分別是代表文本起始與結束的特殊標記。將文本 x 輸入 BERT 後，可得到每個詞元的隱藏狀態：

Hstatus = BERT(x)　　（式2）

其中 Hstatus ∈ ℝn×dh，dh 為隱藏層維度。由於 [CLS] 詞元的位置及自注意力機制的作用，它能彙集整段文本序列的完整資訊。因此，後續流程中我們使用 [CLS] 詞元的隱藏狀態來代表整段文本。

3.3　結構編碼器

圖卷積網路（GCN）在 NLP 中被廣泛用作結構編碼器以聚合節點資訊。GCN 是一種專為圖結構資料設計的神經網路，能透過直接操作節點與邊，有效捕捉節點間的複雜關係及圖的整體結構。GCN 的核心優勢在於能利用節點的局部連接模式，將這些局部資訊整合為對整張圖的全局理解。

本文採用階層式 GCN（Hierarchical-GCN）來聚合細粒度標籤結構的全局關係資訊。階層式 GCN 透過「由上而下（top-down）」「由下而上（bottom-up）」與「自迴路（self-loop）」三種邊，在層內與跨層之間聚合資料流。在此階層圖中，每個節點代表一個對應標籤，每條有向邊代表標籤間關係的相關特徵。每個節點的新特徵表示，是透過結合自身特徵與相鄰節點特徵計算而得——通常包括：對相鄰節點特徵加權、進行線性變換（如乘以權重矩陣），再經非線性激活函數更新節點的特徵表示。

然而，上述變換若為每條有向邊都使用獨立的權重矩陣來編碼資訊，將大幅增加模型的參數量與複雜度，可能導致過度參數化。本文參考既有研究的做法，將此變換簡化為以階層先驗機率作為加權鄰接矩陣。

節點 i 的隱藏狀態是透過其相關聯的鄰居 M(i) = {mᵢ, child(i), parent(i)} 進行編碼，具體如下：

首先，定義節點 i 與其鄰居節點 t 之間的聯合向量 wi,t：

wi,t = ci,txt + dim　　（式3）

其中 ci,t 為階層機率係數（自迴路邊 ci,i=1；由上而下邊 hc(qt,i)=Mi/Mt；由下而上邊 hp(qt,i)=1），xt 為鄰居節點 t 的特徵向量，di∈ℝN×dim 為偏置項。

接著，透過權重矩陣變換與 sigmoid 激活函數計算節點 i 的邊特徵 fi,t：

fi,t = σ(Ufe(t,i)xi + dfi)　　（式4）

其中 Ufe(t,i)∈ℝdim 為從節點 t 到節點 i 的階層方向權重矩陣，dfi∈ℝN 為偏置項。

最後，節點 i 的輸出隱藏狀態 pi 由所有鄰居節點特徵的加權和計算而得，並經 ReLU 激活函數：

pi = ReLU( Σt∈M(i) fi,t ⊙ wi,t )　　（式5）

節點 i 的輸出隱藏狀態 pi 即代表該標籤的表示，捕捉了階層結構資訊。

3.4　負樣本生成與對比學習模組

既有 HTC 研究已取得顯著成果，然而在更深層次上，現有模型仍難以準確分類部分複雜的細粒度標籤。為應對此挑戰，本文採用對比學習來增強這些標籤間的區分度。負樣本的品質是對比學習能否有效發揮作用的關鍵因素。為此，本文提出全新的負樣本生成方法——HiSR，為對比學習提供全面且多樣化的負樣本集合。

核心流程：
  1. HiSR 先以 DFS 演算法遍歷整個標籤樹，為每個標籤生成一條由上而下的序列（該序列從第一層標籤開始，止於該標籤本身）；所有序列共同構成負樣本集合 S。
  2. 每條序列的預測機率 P，為該序列中所有標籤機率的平均值。
  3. 依此構造「正樣本–負樣本」對比損失。
  4. 進一步引入「負樣本–負樣本」比較，依 F1 分數對負樣本分組排序，並在每個訓練回合動態挑選預測機率最高（最具挑戰性）的樣本作為負樣本。

每條序列的預測機率計算公式如下：

P = ( Σi=1L pi ) / L　　（式6）

其中 L 為序列長度，pi 為序列中第 i 個標籤的機率。由此，正負樣本的對比損失函數 Lpn 可表示為：

Lpn = Σj∈S max(0, Pp − Pj + λ)　　（式7）

其中 Pp 為真實標籤（正樣本）的預測機率，Pj 為第 j 條序列（負樣本）的預測機率，λ 為正、負樣本間的邊界間隔（margin）。

然而，僅比較「正樣本–負樣本」會導致模型忽略負樣本之間的細微差異，因此本文進一步引入「負樣本–負樣本」比較。此比較機制能進一步細化負樣本間的區分、增強模型對細粒度標籤細微特徵差異的敏感度，並避免模型將所有負樣本簡單地歸為同一類，從而提升模型分類細粒度標籤的能力。此外，由於 HTC 中不同負樣本可能存在部分重疊的標籤路徑，透過比較這些負樣本，模型能更深入理解階層中的父子與同層（兄弟）關係，進而強化其辨識標籤結構複雜性的認知能力——這對於提升模型在複雜階層標籤系統中的分類效能至關重要。

具體而言，在「負樣本–負樣本」比較中，本文假設：越接近真實標籤的序列，應被賦予越高的預測機率。因此，HiSR 首先計算真實標籤與各生成序列的 F1 分數（HTC 領域常用的評估指標）；接著，將 F1 分數相同的序列分為一組，並依 F1 分數由高到低排序（使越接近真實標籤的序列排在越前面）。最後，在訓練階段的每一回合中，從排序後的各組中挑選預測機率最高者作為負樣本。此動態選擇策略能為對比學習提供最具挑戰性的負樣本，充分發揮對比學習的潛力。「負樣本–負樣本」對比損失函數如下：

Lnn = Σi Σj>i max(0, Pi − Pj + λij)　　（式8）

其中 λij 為間隔（margin）乘以樣本間排名距離，即 λij = (j − i) × λ。

此「負樣本–負樣本」對比損失函數的作用，在於：在缺乏標準樣本的情況下，透過評估不同分數的樣本，提升模型辨識負樣本的能力，因而在對比學習中展現出獨特優勢與廣泛的應用前景。

🔍 深入解析：F1 分數與預測機率 P 究竟是什麼關係？

F1 分數與預測機率 P 其實是兩個獨立來源的量，但透過「排序」與「損失函數」被刻意連結在一起。理解兩者的分工，是讀懂「負樣本–負樣本」比較機制的關鍵。

2. 兩者如何被連結：F1 定順序，P 做選擇與計算損失

第一步（用 F1）：先用 F1 把所有負樣本序列分組、排序——這是一個與模型無關、事先就能算出的「難度基準」。F1 越高（離真實標籤越近），概念上越容易和真實標籤搞混，理論上模型「應該」給它較高的機率。這個排序後續會用在式8的邊界間隔 λᵢⱼ = (j−i)×λ 中，排名差距越大，要求的機率差距（margin）也越大。

第二步（用 P）：在「F1 相同」的同一組內，才去看模型目前對哪個序列給出的預測機率 P 最高，把它挑出來當作這一輪的負樣本。

為什麼要這樣設計？如果只看 F1，選出的負樣本每個 epoch 都一樣（因為 F1 不會變），訓練會缺乏動態性。加入 P 之後，即使兩個序列 F1 相同（語意上一樣接近真實標籤），模型也可能因為當下的參數狀態，對其中一個給出特別高的機率——這代表這正是模型目前最容易搞混、最該被糾正的那個。挑它作負樣本，等於每一輪都在攻擊模型當下最脆弱之處，這就是論文所說的「動態選擇最具挑戰性的負樣本」。

3. 損失函數如何把兩者串起來

式7、式8 的 hinge loss 實際運算用的是 P（不是 F1）：式7（正–負對比）要求真實標籤的 Pp 比負樣本的 Pj 高出至少 λ；式8（負–負對比）要求排名 i 的 Pi 比排名 j（j>i，即 F1 較低、離真實標籤較遠）的 Pj 高出至少 λᵢⱼ。而排名 i, j 這個順序，正是由 F1 分數的排序決定的。

換句話說：F1 負責畫出「理想上機率應該呈現的遞減順序」，訓練損失則強迫模型的實際輸出機率 P 去逼近這個順序——離真實標籤越遠（F1 越低）的序列，模型給的機率就必須被壓得越低，且壓低的幅度（margin）還會隨排名差距擴大。簡言之：F1 是「應該多像」，P 是「模型覺得多像」，訓練目標就是讓「模型覺得」逐漸貼合「應該」的順序，並優先修正模型當下判斷偏差最大（P 虛高）的那個負樣本。

4. 為什麼會出現「F1 相同」的一整組序列？

對標籤樹做 DFS 後，每一個標籤都會生成一條「從第一層走到它自己」的序列。也就是說，若標籤總數是 |L|（WOS 141、NYT 166、RCV1 103），就會產生 |L| 條序列，其中只有一條（或多路徑資料集中的少數幾條）等於真實標籤本身，其餘都進入負樣本集合 S。

而 F1 本質上是一個離散、容易重複的數值，因為 Precision、Recall 都是「重疊標籤數 ÷ 序列長度」這種整數比值算出來的。由於真實標籤集合通常很小（表1顯示 NYT 平均每筆樣本只有 7.6 個標籤、RCV1 只有 3.24 個），每條序列的長度也有限（等於該標籤在樹中的深度，通常 2～8 層），「重疊數／長度」的可能組合數量本來就非常有限。

舉例：假設真實標籤路徑是 Root→News→U.S.→Midwest（4層，4個標籤）。
  • 序列A（標籤「Sports」的路徑）：Root→News→Sports，與真實標籤重疊 2 個（Root、News），長度 3。
  • 序列B（標籤「Education」的路徑）：Root→News→U.S.→Education，重疊 3 個（Root、News、U.S.），長度 4。
只要「重疊數／長度」的組合一致，即使是完全不同標籤的序列，也可能算出一模一樣的 F1 值。

由於全部標籤動輒上百個，而 F1 的可能取值卻被「重疊數」「序列長度」這兩個小整數限制住，依鴿籠原理，上百條序列擠進少數幾個可能的 F1 數值裡，自然會出現大量分數相同的序列——尤其是那些跟真實標籤完全沒有重疊的序列（F1=0），這類序列通常會佔負樣本集合中最大的一群（可對照圖2範例中 F1=0.8、F1=0.5、F1=0 三組，其中 F1=0 那組列出好幾個標籤）。

5. 這正是「負–負樣本」比較機制存在的原因

如果每個 F1 分數都只對應一條序列，那其實會退化成一個簡單的全序排列，不需要額外機制。正是因為同一 F1 分數底下常聚集了一整群語意上「同樣接近／同樣遠離」真實標籤的序列，才需要：

  1. 先把它們分到同一組（因為從 F1／語意角度看，這組序列「應該」被賦予差不多的機率）；
  2. 組內再用當下的模型預測機率 P 決定「這一輪」該挑哪一個當負樣本（因為 F1 分不出組內誰更該被優先糾正，只有模型自己的即時輸出才知道）。
簡言之：「F1 分組」處理的是組間的難度排序，「P 動態挑選」處理的是組內的即時挑戰性——兩者互補，才不會浪費掉那些理論上「同樣重要」但模型表現各異的負樣本。

綜上，對比學習的總損失函數可表示為式9。「正–負樣本」比較策略與「負–負樣本」比較策略的整合，能全面提升模型在 HTC 任務上的表現——此方法不僅優化了模型的特徵表示與分類能力，也為複雜階層標籤結構中對比學習的應用提供了新的思路與方法。

3.5　分類損失與目標函數

依循既有研究做法，本文採用二元交叉熵損失函數 LC 進行分類：

LijC = −yijlog(pij) − (1−yij)log(1−pij)　　（式10）
LC = Σi=1N Σj=1k LijC　　（式11）

其中 yij 為真實標籤，LijC 與 pij 分別為文本 i 在標籤 j 上的二元交叉熵損失與預測機率。

訓練的最終損失函數，是分類損失與 HiSR 損失的組合：

L = LC + α LHiSR　　（式12）

其中 α 為平衡 HiSR 損失權重的超參數。

4.2　基準方法（Baselines）

為驗證本文方法的效能，選取以下具代表性的基準方法：

HiAGM：利用階層感知的多標籤注意力機制，運用標籤依賴的先驗機率生成混合特徵。
HTCInfoMax：透過資訊最大化增強 HiAGM，建模文本與階層間的互動，優化文本–標籤互資訊，並將標籤表示正則化以貼近先驗分佈。
HiMatch：將問題視為語意匹配任務，在聯合嵌入空間中對齊文本與標籤表示，並以此聯合表示進行分類。
HGCLR：透過對比學習增強編碼器表示，並引入新的圖編碼器以提取階層標籤資訊。
HPT：一種階層感知的提示調校（Prompt Tuning）方法，建構動態虛擬模板與標籤詞，並引入零邊界多標籤交叉熵損失。
HJCL：結合實例層級與標籤層級的對比學習技術。
HALB：採用多標籤負向監督方法以強化文本表示對標籤階層的感知，並引入非對稱損失函數解決標籤不均衡問題。
NERHTC：將 HTC 轉化為命名實體識別（NER）任務，結合條件隨機場（CRF）與 Global Pointer 建立階層依賴關係。

4.3　實作細節

本研究以 PyTorch 框架端到端實作模型，選用 Zhou et al.（2020）提出的 HiAGM-TP 變體，將其文本編碼器替換為 Hugging Face Transformers 函式庫中的 bert-base-uncased，其餘預設參數均維持原論文設定。

實驗中，WOS 與 RCV1 的批次大小（batch size）設為 8，NYT 則設為 4；採用 Adam 優化器，學習率設為 1e-5。訓練階段採用提前停止（early stopping）策略：依每個 epoch 後模型在驗證集上的表現，若兩項 F1 分數連續六個 epoch 均未提升，即立即終止訓練。

在對比學習部分，權重 α 設為 0.01；「負樣本–負樣本」的間隔 λ 設為 0.15，「正樣本–負樣本」的間隔設為 0.5。

5.2　局部結構的影響

本文方法旨在解決 HTC 研究中常見的「難以區分細粒度標籤」問題。為此，本文從路徑一致性與標籤粒度兩方面進行進一步實驗。

5.2.1　路徑一致性（Path Consistency）

細粒度標籤分類失誤，可能導致「路徑不一致」——即父節點預測正確而子節點預測錯誤，或子節點預測正確而同一路徑上的父節點預測錯誤。依循既有研究，本文採用路徑約束指標（path-constrained metrics）與路徑基礎指標（path-based metrics）來評估本方法解決路徑不一致問題的效果，進一步證明本方法能有效應對細粒度標籤誤分類的挑戰。

在路徑約束指標（CMicro-F1、CMacro-F1）中，唯有當一個節點的所有祖先節點皆被正確預測時，該節點才被視為預測正確。路徑基礎指標（PMicro-F1、PMacro-F1）則用於評估整條路徑上所有標籤的正確性，但僅適用於「強制葉節點（mandatory-leaf）」資料集，如 WOS。

在三個資料集上的進一步實驗結果見表4與表5。路徑約束指標與路徑基礎指標皆適用於 WOS，且本模型在 WOS 上也達到 SOTA，顯示本方法在如 WOS 這類兩層結構資料集上表現優異。而在 RCV1 與 NYT 上僅能使用路徑約束指標：在 RCV1 上，HiSR 一如預期地超越所有既有模型；然而 NYT 的八層複雜結構與大量標籤，對 HiSR 構成一定挑戰。

6　結論

本文提出一種名為階層序列排序（HiSR）的負樣本生成方法，為對比學習提供高品質的負樣本，藉此解決 HTC 任務中普遍存在的「相似細粒度標籤難以區分」問題。HiSR 生成的負樣本不僅能將細粒度標籤間的細微差異傳遞給模型，其依序性特徵所引入的「負樣本–負樣本」比較，也有助於模型更深入理解標籤層級間的複雜關係。HiSR 為建構階層結構資料的負樣本提供了一種新思路。實驗顯示，HiSR 相較所選基準方法取得了一致的效能提升，並在部分資料集上達到 SOTA 表現。

限制（Limitations）

實驗結果顯示 HiSR 能提升模型對細粒度標籤的區分能力，但在 NYT 資料集上並未達到 SOTA。作者推測，這是由於 NYT 層數過多，且存在多條不同長度的路徑，導致 HiSR 難以構造出完美的負樣本；此外，所採用的排序指標也可能並非最優解。作者表示將在未來工作中進一步研究上述問題。
