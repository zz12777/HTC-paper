KG-HTC：將知識圖譜融入大語言模型，實現有效的零樣本層級文字分類

KG-HTC: Integrating Knowledge Graphs into LLMs for Effective Zero-shot Hierarchical Text Classification

Qianbo Zanga,*、Christophe Zgrzendekb、Igor Tchappia、Afshin Khadangia、Johannes Sedlmeirc
a 盧森堡大學 安全、可靠與信任跨學科中心（SnT）　b Enovos Luxembourg S.A.　c 明斯特大學

摘要

ABSTRACT

層級文字分類（Hierarchical Text Classification, HTC）是指將文件分配到按照分類體系（taxonomy）組織起來的標籤中。以往關於 HTC 的研究大多聚焦於監督式方法。然而在真實場景中，由於缺乏標註資料，採用監督式 HTC 往往十分困難；此外，HTC 還常常面臨標籤空間巨大、長尾分佈嚴重等問題。

本文提出 KG-HTC（Knowledge Graphs for zero-shot Hierarchical Text Classification），旨在透過將知識圖譜與大語言模型（LLM）相結合，在分類過程中提供結構化的語義上下文，從而在實際應用中解決上述 HTC 難題。我們的方法採用檢索增強生成（Retrieval-Augmented Generation, RAG）思路，從與輸入文字相關的知識圖譜中檢索出相關子圖。KG-HTC 能夠幫助 LLM 理解不同層級標籤的語義。

我們在三個開源 HTC 資料集——WoS、DBpedia 與 Amazon——上評估了 KG-HTC。實驗結果表明，在嚴格零樣本設定下，KG-HTC 顯著優於三種基線方法，尤其是在層級更深的分類任務上取得了大幅提升。這一評估證明了將結構化知識融入 LLM 有助於解決 HTC 中大規模標籤空間與長尾標籤分佈的挑戰。

程式碼已開源：github.com/QianboZang/KG-HTC

1　引言

文字分類是自然語言處理中的一項基礎任務，其目標是把給定文字分配到預先定義的類別中。層級文字分類（HTC）是文字分類的一個特殊而日益重要的擴充套件：標籤不再是扁平的，而是被組織在一個多層級的分類體系（taxonomy）中。HTC 需要把文字資料歸入具有父子關係的多層標籤體系，不同層級的標籤構成一個層級化的分類樹。圖 1 展示了來自 Amazon 商品評論資料集的一個例子：分類體系的根節點是資料集名稱，一條評論需要被依次分類到多個層級的標籤上。圖中示例文字可依序分類為「health personal care（保健個護）」「household supplies（家居用品）」「dishwashing（洗碗用品）」。HTC 已被成功應用於多個領域，包括電商商品分類、電子參與平臺的層級主題建模，以及細粒度的文獻管理等。

然而在真實應用中，HTC 往往面臨以下三項重大挑戰中的一項或多項：

  1. 標註資料匱乏。在多個層級上人工標註自定義資料的成本極高，這一問題在如零售系統這類分類體系隨新產品線不斷演化的動態環境中尤為嚴重。
  2. 標籤空間龐大。實際的分類體系普遍擁有大規模標籤空間：例如 Amazon 商品評論資料集的分類體系包含超過 500 個葉子類別。
  3. 長尾分佈嚴重。真實資料集中少數高頻類別佔據了絕大多數樣本，而大部分類別樣本稀少。例如，我們的統計分析顯示，Amazon 資料集第三層級中最高頻的 15% 類別佔據了總樣本量的 80%，而排名後 50% 的類別合計僅佔樣本量的 6%。

基於以上三點原因，與扁平文字分類不同，標準的監督式方法在許多行業場景中並不適用。因此，研究者們逐漸轉向零樣本學習方法來解決 HTC 問題。近期研究大致可歸納為三條主要技術路線：

  • 路線一：基於提示詞的上下文學習。該方法透過精心設計的提示詞，利用預訓練 LLM 的上下文學習能力完成分類。Halder 等人的方法將任意文字分類任務轉化為通用的二元分類問題，讓 LLM 對標籤空間中的每個標籤輸出「真/假」。但由於 HTC 的標籤空間極大，該方法完成一次分類往往需要多輪迭代。
  • 路線二：基於嵌入模型的距離度量。該方法利用由預訓練 LLM 轉化而來的嵌入模型，計算輸入文字與標籤之間的距離進行分類。Bongiovanni 等人提出 Z-STC，將相似度分數沿層級結構向上傳播，以此最佳化上層標籤的分類結果。
  • 路線三：嵌入模型與 LLM 分類相結合。Paletto 等人提出 HiLA，利用 LLM 在現有分類體系底部生成新的標籤層，再沿用 Z-STC 完成分類。

然而，Bongiovanni 等人與 Paletto 等人的方法在層級較深的標籤上分類效果均不理想。

為此，本文提出 KG-HTC——一種透過將知識圖譜（KG）融入 LLM 來增強 HTC 效果的新方法，重點面向嚴格零樣本學習（strict zero-shot learning）設定。由於有向無環圖（DAG）天然適合表示 HTC 中標籤的層級結構，將 LLM 與知識圖譜相結合對這一任務極具潛力。具體而言，我們將分類體系表示為基於 DAG 的知識圖譜，並計算文字與各層級標籤嵌入之間的餘弦相似度。透過設定預先確定的閾值，在每個層級篩選出與輸入文字語義高度相關的候選標籤。隨後，系統依據這些候選標籤，從完整的標籤知識圖譜中動態檢索出與該文字最相關的子圖。對於檢索到的子圖，我們採用一種「向上傳播」演算法，系統性地列舉從葉子節點到根節點的所有可能路徑，每條路徑代表一條完整的、經過反轉的層級標籤序列。這些結構化序列隨後被拼接為提示詞，輸入 LLM 完成零樣本分類任務。

我們在三個公開資料集上評估了該方法，均取得了新的最優結果。在不依賴任何標註資料的前提下，KG-HTC 顯著增強了模型應對長尾與稀疏標籤問題的能力。與 Bongiovanni 等人及 Paletto 等人的方法相比，隨著標籤層級加深，KG-HTC 的效能下降幅度明顯更小。

本文三大貢獻
  1. 提出 KG-HTC 方法，在嚴格零樣本設定下將知識圖譜融入 LLM 以完成 HTC 任務；
  2. 實現了一套新穎的流程：基於餘弦相似度從標籤分類體系中語義化地檢索相關子圖，並將其轉化為結構化提示詞；
  3. 在三個開源 HTC 資料集上對 KG-HTC 進行深入評估，並與此前的最優方法進行對比。

本文餘下部分安排如下：第 2 節介紹 KG-HTC 方法；第 3 節描述實驗設定；第 4 節分析實驗結果；第 5 節綜述相關工作；第 6 節總結全文。

2　方法

2.1　問題定義 Problem Identification

基於 LLM 的零樣本文字分類可被形式化為一個生成式分類任務。給定輸入文字序列 x = (x₁, x₂, …, xₙ)（n 為文字長度），LLM 採用 Top-p 取樣策略生成輸出文字 y ～ LLM(x)。在分類場景下，標籤集合記為 C，生成文字 y 隨後被對映為預測標籤 ĉ ∈ C。

我們沿用 Paletto 等人建立的數學框架，關鍵符號彙總於表 1。在層級文字分類中，標籤空間 C 中的全部標籤被組織為一個層級分類體系 C = (C¹, C², …, Cᴸ)，其中 L 為分類體系的最大深度（即層級數）。為形式化描述標籤間的依賴關係，我們採用 [25] 提出的上下箭頭記號：↑cᵢˡ 表示 cᵢˡ 在層級結構中的父節點，↓cᵢˡ 表示 cᵢˡ 的子節點集合。對所有 l > 1，每個標籤 cᵢˡ ∈ Cˡ 都必須滿足結構約束 ↑cᵢˡ ∈ Cˡ⁻¹。層級文字分類任務要求 LLM 生成一組輸出 (y¹, y², …, yᴸ)，對應分類體系中各層級的預測標籤 (ĉ¹, ĉ², …, ĉᴸ)，其中 ĉˡ ∈ Cˡ。

2.2　系統架構 System Architecture

圖 2 展示了 KG-HTC 的完整流程。首先，我們將全部標籤分別儲存到一個圖資料庫和一個向量資料庫中。給定輸入文字，我們依次在向量資料庫中檢索出每個層級 l 上相似度最高的候選標籤集合 Qˡ，並透過檢查相鄰層級候選標籤之間的父子關係，從圖資料庫中檢索出一個有效子圖。隨後，我們將檢索到的子圖中的一組路徑轉化為結構化提示詞，與分類提示詞模板拼接。最後，我們藉助上下文學習（In-context Learning）完成零樣本文字分類。

2.3　層級標籤的儲存 Storage of Hierarchical Labels

第一步，我們分別將全部標籤存入一個圖資料庫和一個向量資料庫。在層級文字分類中，標籤的分類體系可被視為一個 DAG 知識圖譜，多層標籤之間透過層級隸屬關係相互連線。透過顯式定義各層標籤間的關係路徑，LLM 能夠建立起對各個標籤及其在層級結構中概念邊界的結構化理解。

例如，圖 3 中的輸入既可能被分類為「dishwashing（洗碗）」，也可能被分類為「cleansers（清潔劑）」。但在 Amazon 商品評論資料集的分類體系中，「cleansers」是「bath body（沐浴身體護理）」的子節點，也就是說「cleansers」的概念邊界屬於「human cleansers（人體清潔用品）」範疇，因此 LLM 應將該輸入正確分類為「dishwashing」。這種基於圖結構的知識表示為 LLM 帶來雙重優勢：一方面為文字處理任務建立了顯式的語義導航路徑，另一方面也構建了拓撲約束，有助於在零樣本場景中透過改善語義消歧來顯著提升分類準確率。

2.4　子圖檢索 Subgraph Retrieval

已有實證研究表明，檢索增強生成（RAG）框架在開放式問答任務中具有顯著優勢。HTC 中的一項核心挑戰正是標籤空間龐大——分類體系往往涵蓋海量類別。透過在向量資料庫中依據相似度動態檢索相關文件並結合上下文學習，RAG 能有效提升生成結果的事實準確性。

Li 等人的研究表明，LLM 在處理長上下文以及大規模標籤空間的分類任務時存在明顯侷限。若直接將完整知識圖譜編碼輸入 LLM，可能因資訊過載或注意力稀釋而導致效能下降。為緩解這一問題，我們提出一種 RAG 增強框架：根據輸入文字動態地從完整知識圖譜中檢索出語義相關的子圖（子樹）成分。這些檢索到的子圖隨後被結構化為上下文提示詞，使分類器能夠優先關注關鍵的層級依賴關係，同時抑制無關噪聲（詳見 2.5 節）。

具體而言，對每個層級 l，我們計算輸入文字嵌入與該層級全部標籤嵌入之間的餘弦相似度距離：

d꜀(x, cᵢˡ) = 1 − S꜀( Ψ(x), Ψ(cᵢˡ) )　　……（式 1）

其中 Ψ: X → Rd 為嵌入函式，S꜀(·,·) 表示餘弦相似度運算元。隨後我們在第 l 層檢索出相似度最高的候選標籤集合：

Qˡ = { cᵢˡ ∣ d꜀(x, cᵢˡ) ≤ τₗ }　　……（式 2）

其中 τₗ 為該層級的相似度閾值。

為保證層級一致性，我們進一步透過檢查相鄰層級候選標籤之間的父子關係來校驗跨層依賴：某個候選標籤 cᵢˡ ∈ Qˡ，僅當其父標籤 ↑cᵢˡ 也屬於 Qˡ⁻¹ 時才成立。演算法 1 給出了以輸入文字 x 為查詢、檢索子圖的完整流程。

演算法 1：子圖檢索（Subgraph Retrieval）
輸入：輸入文字 x，標籤集合 {C¹, C², …, Cᴸ}
輸出：檢索得到的子圖 G

初始化空圖結構 G ← ∅；
計算輸入文字的嵌入 Ψ(x)；
for l ← 1 到 L do
  計算第 l 層全部標籤的嵌入 Ψ(cᵢˡ)；
  依式(1)計算 d꜀；
  依式(2)檢索候選集合 Qˡ；
end
for l ← 2 到 L do
  for 每個 cᵢˡ ∈ Qˡ do
    if ↑cᵢˡ ∈ Qˡ⁻¹ then
      將節點 ↑cᵢˡ 與 cᵢˡ 加入 G；
      將邊 (↑cᵢˡ, cᵢˡ) 加入 G；
    end
  end
end
刪除 G 中重複的邊 (↑cᵢˡ, cᵢˡ)；
return G；

2.5　子圖轉提示詞 Transformation from Subgraph to Prompt

對於輸入文字 x，我們首先透過演算法 1 檢索得到子圖 G。為有效地將知識圖譜注入 LLM，我們採用一種策略：透過父子邊連線，將圖結構轉化為一組路徑。具體來說，每個子圖都會被序列化為一組從根到葉的層級路徑。這種基於「鏈」的表示方式在保持結構一致性的同時，也相容了 LLM 的序列化輸入格式。對於 HTC 任務而言，路徑的長度等於分類體系的深度 L。

LLM 無法直接理解圖結構資訊，因此我們需要將子圖轉化為提示詞——一種可行方式是將圖中的路徑作為提示詞輸入，供模型進行圖理解與推理。子圖中有效的層級標籤路徑會透過「向上傳播」被保留為上下文提示詞。「向上傳播」演算法本質上是一個迴圈遍歷演算法，系統性地探索從層級結構中的終端葉子節點到根節點的全部可能路徑：從最終層級中任意一個初始節點 cᵢᴸ ∈ Cᴸ 出發，演算法 2 會逐步訪問其父節點直至到達根節點，然後回溯以探索其他分支。這種窮舉式遍歷保證了對全部有效路徑組合的完整列舉。得到全部路徑組合後，每條路徑 Pᵢ 中元素的順序會被反轉，以確保方向一致性（從第一層到第 L 層），最終輸出為完整路徑集合 P = {P₁, P₂, …}。每條路徑 Pᵢ = (pᵢ¹ → pᵢ² → … → pᵢᴸ) 代表一條相互連線的節點序列，其中 pᵢˡ ∈ G 且 pᵢˡ ∈ Cˡ。

演算法 2：由子圖生成層級標籤路徑（From Subgraph to Hierarchical Label Paths）
輸入：輸入文字 x，由演算法 1 檢索得到的子圖 G
輸出：層級路徑集合 {P₁, P₂, …}

初始化路徑集合 P ← ∅；
for 每個葉子節點 cᵢᴸ ∈ Cᴸ do
  初始化棧結構 S ← {[cᵢᴸ]}；
  for l ← L 到 1 do
    將 cᵢᴸ 的父節點 ↑cᵢˡ ∈ Cˡ⁻¹ 壓入棧 S；
  end
  將 S 加入 P；
end
return P；

我們可以藉助「→」連線相鄰層級的節點，把檢索到的子圖中的一組路徑轉化為結構化提示詞。這種結構化上下文能夠幫助 LLM 在分類過程中識別層級約束關係。提示詞 1 給出了 Amazon 商品評論資料集上這種多層標籤路徑提示詞的示例。

2.6　各層級分類 Classification of Each Level

本方法透過將從檢索子圖中提取的結構化上下文與分類提示詞模板拼接，充分利用上下文學習與提示工程。拼接後的提示詞隨後輸入 LLM 進行推理。提示詞 2 給出了 Amazon 商品評論資料集上分類别範本的示例。

提示詞 2：Amazon 商品評論資料集分類别範本
Classify the review of a product into one of the following categories: {category_text}. You must directly output one of the categories and do not add ", ', and *. Here is the partial knowledge graph: """ {knowledge} """

（請將該商品評論分類到以下類別之一：{候選類別}。必須直接輸出其中一個類別名稱，且不得新增引號或星號。這裡是部分知識圖譜：{檢索到的知識}。）

對於 HTC 任務，我們採用逐層分類策略：模型先預測第一層標籤，再依次對更深層級的標籤進行分類，直至到達最後一層。HTC 的一大挑戰在於候選標籤數量龐大——若在單條提示詞中提供全部可能的標籤，往往會導致效能下降。不過，由於評估資料集中第一層標籤數量通常較少（均不超過 10 個），我們可以直接將全部第一層標籤納入提示詞，從而簡化推理流程並提升分類效果。

對於第一層之後的分類，模型會使用上一層級的預測結果作為當前層級的約束條件。例如第 l 層的預測標籤為 yˡ，則第 l+1 層的候選標籤集合主要由上一預測結果 yˡ 的子類別 ↓yˡ 構成，並輔以透過式(2)檢索出的額外候選標籤 Qˡ⁺¹。這一設計有助於緩解上一層預測錯誤帶來的影響，提升整體分類流程的魯棒性與準確率。演算法 3 展示了 KG-HTC 的完整流程。

演算法 3：KG-HTC 完整流程
輸入：輸入文字 x，提示詞模板 P
輸出：預測的層級標籤 y = (y¹, y², …, yᴸ)

初始化預測標籤集合 y ← ∅；
透過演算法 1 檢索子圖 G；
將 G 轉化為層級標籤路徑 P；
for 層級 l ← 1 到 L do
  if l ← 1 then
    prompt ← concat(x, P, C¹)　（依提示詞 2 拼接）；
  else
    依式(2)檢索候選集合 Qˡ；
    prompt ← concat(x, P, Qˡ ∪ ↓yˡ⁻¹)　（依提示詞 2 拼接）；
  end
  yˡ ← LLM(prompt)；
  將 yˡ 加入 y；
end
return y = (y¹, …, yᴸ)

3　實驗

3.1　資料集 Dataset

  • Amazon 商品評論資料集（Amazon）。包含 Amazon 應用中的商品評論，每條資料包括標題與描述，需按照三層級分類體系分類，各層級分別有 6、64、510 個標籤類別。
  • Web of Science（WoS）。關於科學研究文獻的資料集，涵蓋自然科學、社會科學、人文與藝術等多個領域，廣泛用於學術研究、文獻計量分析與科學評價。每條資料依據兩層級分類體系分類，兩層分別有 7 與 134 個標籤類別。
  • DBpedia。一個基於維基百科構建的開放知識庫專案，科學家從維基百科中抽取並轉化海量資訊，以結構化、標準化格式呈現，DBpedia 內部資料構成一個龐大而複雜的知識圖譜，支援使用者進行跨領域知識探索。每條資料依據三層級分類體系分類，各層分別有 9、70、219 個標籤類別。

3.2　評估指標 Metric

我們採用 F1-macro（宏平均 F1 分數）作為評估指標，即對所有類別的 F1 分數取算術平均。F1-macro 能確保稀有類別對最終指標的貢獻與其他類別相同，從而避免在類別分佈不均衡的場景下產生過於樂觀的效能估計，因而適用於類別不平衡的資料集。其定義為：

F1-macro = (1/C) · Σᵢ₌₁ᶜ F1ᵢ　　……（式 3）

其中 C 為類別總數，第 i 類的 F1 分數為精確率與召回率的調和平均：

F1ᵢ = 2 × (Precisionᵢ × Recallᵢ) / (Precisionᵢ + Recallᵢ)　　……（式 4）

為進一步評估「標籤空間龐大」與「長尾分佈」這兩大挑戰疊加的影響，我們還引入了一個名為「平均衰減率（average decay rate）」的指標，因為隨著層級加深，標籤空間會變大、資料分佈也會更加偏斜：

decayᵢ = ( F1-macro(第 i−1 層) − F1-macro(第 i 層) ) / F1-macro(第 i−1 層)　　……（式 5）
decay_avg = (1 / (L−1)) · Σᵢ₌₂ᴸ decayᵢ　　……（式 6）

3.3　實驗設定 Experiment Setup

基線方法。我們將本方法與兩類基線進行比較：第一類是弱基線——LLM 針對每一層標籤直接進行分類；第二類是兩項此前研究 Z-STC 與 HiLA（見第 2 節介紹）作為強基線，二者是此前嚴格零樣本設定下的最優方法。

實驗細節。為與強基線研究保持一致，我們選用 GPT-3.5-turbo 模型；RAG 系統的嵌入模型採用 text-embedding-ada-002；圖資料庫採用 Neo4j；向量資料庫採用 ChromaDB。

在全部資料集的實驗中，我們將 GPT-3.5-turbo 的 temperature 設為 0.4，Top-p 設為 0.4，以保證生成結果的穩定性。對於 RAG 系統，我們在 DBpedia 與 Amazon 資料集上設定相似度閾值 τₗ，使第二層檢索出 10 個候選標籤、第三層檢索出 40 個候選標籤；在 WoS 資料集上設定閾值，使第二層檢索出 20 個候選標籤。這些超引數均透過實驗方式確定。

由於 LLM 生成過程存在固有隨機性，生成輸出有時會落在預定義標籤空間之外。此時，我們以固定隨機種子 42，從標籤空間中隨機取樣一個標籤，將無效輸出轉化為有效標籤，以確保結果可復現。

5　相關工作

層級文字分類。HTC 任務最早由 Sun 與 Lim 提出，他們建議使用支援向量機（SVM）分類器加以解決。隨後，Kowsari 等人探索了多種深度學習方法，為分類體系的每個層級分別訓練不同的深度神經網路。近期，Liu 等人提出將知識圖譜融入 HTC：他們採用圖神經網路（GraphSAGE）編碼知識圖譜，並將圖嵌入與 BERT 文字嵌入相結合進行微調，這一方法目前是監督式設定下的最優方法。然而監督式方法在工業應用中面臨挑戰，其主要問題在於標註資料的匱乏——在多個層級上標註資料的成本往往過高。隨著 LLM 效能不斷提升，零樣本推理在眾多領域中日益普及。

零樣本 HTC。與本文嚴格零樣本設定相關的研究主要有三項：

  • Halder 等人提出「任務感知表示（Task-Aware Representation）」方法，用於零樣本文字分類，將任意文字分類任務轉化為通用的二元分類問題——給定文字與一組標籤，LLM 判斷該標籤是否匹配（輸出「真」或「假」）。但由於 HTC 標籤空間龐大，該方法完成一次分類需要多輪迭代。
  • Bongiovanni 等人提出 Z-STC（Zero-shot Semantic Text Classification），採用「向上分數傳播（Upward Score Propagation, USP）」方法處理 HTC。該方法利用 BERT、RoBERTa 等預訓練深度語言模型，分別將文件與分類標籤編碼到同一語義向量空間中，再透過餘弦相似度計算每個標籤的先驗相關性分數。結合分類體系的層級結構，USP 會遞迴地將下層標籤的相關性分數向上傳播至其父節點——其核心思想是：若某個子標籤與待分類內容高度相關，則其父標籤也應被視為相關。這種層級化的分數傳播機制有效地將區域性語義線索融入全域性分類體系，從而提升整體分類效能。
  • Paletto 等人提出 HiLA（Hierarchical Label Augmentation）方法，利用預訓練 LLM 為現有標籤體系的葉子節點生成額外的子標籤。由於將完整層級體系直接輸入 LLM 會面臨 token 數量限制的挑戰，他們採用迭代方式為每個分支生成擴充套件子標籤，以避免重複與標籤重疊；此外，Paletto 等人在新生成的更深層級上應用 Bongiovanni 提出的 Z-STC 方法完成 HTC 任務。因此，HiLA 是嚴格零樣本設定下此前的最優方法。

然而，正如本文第 4 節所展示的那樣，Bongiovanni 與 Paletto 的方法在層級更深的標籤上分類準確率均較低。這是因為隨著分類體系層級加深，對應單層分類任務的標籤空間會變得更大，標籤分佈也會更加偏斜。

檢索增強生成（RAG）。RAG 能夠在上下文學習推理過程中，動態地從外部語料庫或資料庫檢索相關資訊。圖 RAG（Graph RAG）將 RAG 擴充套件為透過知識圖譜檢索相互關聯的實體與關係，從而實現更豐富的上下文理解。RAG 與圖 RAG 均已在開放域問答任務中展現出顯著提升。然而，目前將 RAG 與圖 RAG 應用於文字分類的研究仍較為有限。

6　結論

監督式 HTC 方法在工業應用中面臨諸多挑戰。本文提出 KG-HTC——一種利用知識圖譜與大語言模型完成 HTC 任務的零樣本方法。KG-HTC 能夠動態檢索出與輸入文字語義相關的子圖並構建結構化提示詞，從而在嚴格零樣本場景下顯著提升分類效能。實驗結果表明，KG-HTC 在三個開源資料集（Amazon、WoS、DBpedia）的零樣本設定下均達到最優效能，且在更深層級標籤的分類上提升尤為顯著。

7　侷限性

本研究的一項侷限在於假設已有一個完整且正確的標籤分類體系可供使用。因此，知識圖譜中存在的任何不準確或錯誤都可能導致本方法效能下降。我們未來的研究方向將聚焦於如何更高效地利用大語言模型構建穩健且準確的知識圖譜。此外，本文所用的評估資料集也可能被用於 LLM 的後訓練階段。
