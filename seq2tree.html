§摘要

階層式文本分類（Hierarchical Text Classification, HTC）是一項具挑戰性的任務：一份文件需要被指派到一個預先定義的分類體系（taxonomy）中、彼此具有階層結構的多個類別上。以往絕大多數研究把 HTC 當作「扁平化的多標籤分類」（flat multi-label classification）問題來處理，這樣的做法必然會導致「標籤不一致」（label inconsistency）問題。本文將 HTC 重新表述為一個序列生成任務，並提出序列到樹（Sequence-to-Tree, Seq2Tree）框架，用以建模階層式的標籤結構。此外，本文設計了一種帶有動態詞表（dynamic vocabulary）的受限解碼（constrained decoding）策略，以確保生成結果的標籤一致性。相較於既有方法，本文所提出的方法在三個基準資料集上都取得了顯著且一致的效能提升。

1緒論

階層式文本分類是一種特殊的多標籤文本分類問題，其目標是將每份文件指派到一個分類體系（taxonomic hierarchy）中一組相關的節點上，如下方圖 1(a) 所示。HTC 有許多實際應用場景，例如商品類目分類、細粒度實體類型識別，以及新聞分類等。

既有方法大致可分為兩類：局部方法（local approaches）與全局方法（global approaches）。局部方法傾向於為不同層級建構多個局部分類器，但通常會忽略分類體系的整體結構資訊。近年來全局方法已成為 HTC 的主流做法——使用單一模型同時處理所有類別，並引入各種策略來捕捉標籤空間的階層資訊，例如動態路由（dynamic routing）、雙曲空間標籤嵌入（hyperbolic label embedding）、Tree-LSTM 與圖卷積網路（GCN）等。然而，由於這些方法本質上仍是把 HTC 視為扁平化的多標籤分類任務，它們的分類結果都會遭遇「標籤不一致」的問題。

如圖 1(a) 所示，輸入文件的真實標籤（綠色節點）分屬兩條路徑；而傳統多標籤分類方法可能產生如圖 1(b) 的預測結果，出現如「紀錄片」（Documentary）與「公司」（Company）這類孤立節點——它們依照傳統的 HTC 評估指標，仍會被視為有效的正確預測。然而，由於 HTC 任務的本質，每個節點的預測結果理應與其祖先節點的預測結果保持一致，不應互相衝突。這種孤立預測與「路徑不一致」的現象，無法滿足許多實際應用場景的需求。本文的目標即是解決 HTC 中的這個「標籤不一致」問題。

為了讓分類結果滿足「標籤一致性」，我們必須聚焦於分類體系中路徑內的標籤依賴關係，而非個別節點。本文將此與樹狀結構的深度優先走訪演算法（DFS）相結合——DFS 能確保同一路徑上的節點以「由上而下」的順序被走訪到。受先前一些將序列生成方法用於各類 NLP 任務的研究啟發，本文提出序列到樹（Seq2Tree）框架來處理 HTC：首先利用 DFS 將階層式標籤轉換為線性化的標籤序列，再以傳統 seq2seq 的方式，將文件文本映射到對應的標籤序列。此外，本文設計了一種受限解碼策略（Constrained Decoding, CD），利用階層式的標籤依賴關係來引導生成過程：每個時間步所產生的候選標籤，會被限制在上一時間步生成節點的子節點範圍內。這樣一來，除了確保結果的標籤一致性之外，本方法在訓練過程中也能充分利用階層式標籤的語意與結構資訊。

本文主要貢獻
  1. 提出一個帶有受限解碼策略的序列到樹生成框架，可有效保證 HTC 結果的標籤一致性；
  2. 提出兩項新的 HTC 評估指標：C-MicroF1 與 C-MacroF1，比現有指標更合理、更貼近實際應用場景；
  3. 在三個基準資料集上進行實驗，結果顯示本方法在傳統評估指標與本文提出的新指標上，皆優於既有的強力基準方法。

2方法論

本文的目標是利用序列生成架構來解決 HTC 任務。為此，需要先將分類體系轉換為序列（即「標籤線性化」）。本節先給出問題定義，接著分別介紹標籤線性化（LL）方法，以及具備受限解碼策略（CD）的模型架構。

2.1問題定義

將 HTC 任務表述為映射 F: (X, T) → Y，其中 X = {X₁, ..., X_N} 表示輸入文件集合，T = {V, E} 為預先定義的分類體系（V 為標籤節點集合，E 表示節點之間的父子關係），Y = {Y₁, ..., Y_N} 為文件集合對應的目標標籤集合。任務目標是學習一個模型 F，將新文件 Xᵢ = {x₁, ..., x|Xᵢ|} 映射到其目標標籤集合 Yᵢ = {y₁, ..., y_ki}（Yᵢ ⊆ T），其中 kᵢ 為標籤數量，且 kᵢ ≤ |V|。

2.2基於 DFS 的標籤線性化

標籤線性化（Label Linearization, LL）的做法十分直觀：依循 DFS 演算法進行。如圖 2 所示，文件的目標標籤 Yᵢ 構成分類體系 T 的一個子樹。依 DFS 演算法，這些標籤可被線性化為：

Root→ 娛樂→ 電影→ 紀錄片→ POP→ POP→ POP→ 商業→ 公司→ POP→ POP

其中 POP 代表「回溯」操作，通常在走訪到子樹的葉節點之後立即執行。例如圖 2 中，當走訪到葉節點「紀錄片」後，必須連續執行三次 POP 才能回到 Root 節點，開始一條新的路徑 {Root-商業-公司}。由於 DFS 演算法是可逆的，這種基於 DFS 的線性化方式，等同於把分類體系的結構資訊注入到標籤序列之中。

2.3受限解碼的 Seq2Tree

與傳統 Seq2Seq 範式相同，Seq2Tree 同樣由兩個部分組成：編碼器（Encoder）與解碼器（Decoder），其架構如圖 3 所示。

編碼器：給定輸入序列 Xᵢ，編碼器將其編碼為隱藏向量表示 Hᵢ = {h₁, ..., h|Xᵢ|}：

Hᵢ = Encoder(x₁, ..., x|Xᵢ|)　　（公式 1）

解碼器：輸入序列編碼完成後，解碼器逐步預測 DFS 標籤序列。具體而言，在生成的第 i 個時間步，解碼器根據上一時間步生成的詞元 ŷᵢ₋₁，預測第 i 個詞元 ŷᵢ 及其對應的解碼器狀態：

ŷᵢ, hᵈᵢ = Decoder_c([Hᵢ, hᵈ<ᵢ], ŷᵢ₋₁, T),　　ŷᵢ ∈ DV_ŷᵢ　　（公式 2）

其中 Decoder_c 表示帶有受限解碼（CD）的解碼器，hᵈ<ᵢ 為先前時間步的解碼器狀態。輸出序列以詞元 <bos> 開始，以 <eos> 結束。DV_ŷᵢ 表示生成 ŷᵢ 時所使用的動態詞表，其產生過程詳見演算法 1。

在預測 ŷᵢ 時，會執行帶動態詞表的 CD 策略。在大多數情況下，候選詞元會被限制在分類體系 T 中、由標籤依賴關係所決定的 ŷ_cur（目前所在節點）的子節點範圍內。如圖 3 所示，模型需要決定第 4 個解碼時間步應生成哪個標籤——由於模型上一步生成了「電影」，根據 T 的標籤依賴關係，候選詞表被限制為 {POP, 紀錄片, 動作片}，而非整個詞表。如此一來，便能在解碼過程中確保標籤一致性。

訓練階段，每筆樣本為一組（文本序列, 線性化標籤序列）配對，訓練目標定義為以下負對數概似損失（negative log likelihood loss）：

L = − Σ_(X, Ŷ)∈(X, Ŷ)　log( P_θ(Ŷ | X, T) )　　（公式 3）

P_θ(Ŷ | X, T) = ∏ᵢ P_θ(ŷᵢ | ŷ<ᵢ, X, T)　　（公式 4）

其中 θ 為模型參數，ŷ<ᵢ 表示先前已生成的標籤。P_θ(ŷᵢ | ŷ<ᵢ, X, T) 是在動態候選詞表 DV_ŷᵢ 上的機率分布，透過 softmax(·) 正規化得到。

演算法 1　動態詞表生成（Dynamic Vocabulary Generation）輸入：已生成的詞元 ŷ₁, ..., ŷᵢ₋₁；分類體系 T 輸出：動態詞表 DV_ŷᵢ NodeStack = () for j = 0 to i − 1: if ŷⱼ is POP: NodeStack.pop() else: NodeStack.add(ŷⱼ) ŷ_cur = NodeStack.pop() if ŷ_cur is 葉節點 (Leaf Node): DV_ŷᵢ = {POP} else: DV_ŷᵢ = { child_T(ŷ_cur), POP } return DV_ŷᵢ

亦即，演算法會用一個節點堆疊（NodeStack）來追蹤目前所在路徑：遇到非 POP 的詞元就入堆疊，遇到 POP 就出堆疊；取出堆疊頂端節點作為目前節點 ŷ_cur，若該節點是葉節點，則唯一合法的下一步只能是 POP；否則合法的下一步是該節點在 T 中的所有子節點，加上 POP（代表提前結束該子路徑）。

推論階段，本文採用集束搜索（beam search）策略生成輸出標籤序列：

Ŷ* = argmax_Ŷ　log( P_θ*(Ŷ | X, T) )
    = argmax_(Ŷ:{ŷ₁,...,ŷ_ki})　log ∏ᵢ P_θ*(ŷᵢ | ŷ<ᵢ, X, T)　　（公式 5）

最終得到預測標籤序列 Ŷ* = {ŷ₁*, ..., ŷ_ki*}。本文以 T5-Base 作為骨幹網路來實現 Seq2Tree，更多實作細節詳見第 3.1 節。

基準方法：本文將所提方法與以下 HTC 模型進行比較：SGM、HMC-Capsule、HiLAP-RL、HiAGM、HTCInfoMax、HiMatch 及 HiMatch-BERT。由於 SGM 同樣是生成式的 HTC 方法，本文另外實作了一個變體 SGM-T5（將原本以 LSTM 為基礎的編解碼器骨幹替換為 T5）以進行公平比較。在這些基準方法中，HiMatch-BERT 是當前最先進（state-of-the-art）的模型。此外，HiLAP-RL 是唯一嘗試處理「標籤不一致」問題的方法，它利用深度強化學習來解決此議題；該研究也提到「標籤不一致」問題可透過後處理（post-processing）方式解決，即簡單地將孤立節點的祖先節點也一併指派為預測結果。因此，本文也在 HiMatch-BERT 上實作了此後處理方法，以驗證其實際效果。

評估指標：除了既有研究廣泛採用的 Micro-F1 與 Macro-F1 之外，本文提出兩項新指標：路徑受限的 Micro-F1（C-MicroF1）與路徑受限的 Macro-F1（C-MacroF1）。這兩個新指標與傳統指標的差異在於：只有當某節點的所有祖先節點也都被正確預測為「真」時，該節點的預測結果才會被視為「真」。以圖 1(b) 為例，儘管模型對「紀錄片」與「公司」做出了正確的預測，但由於它們的父節點預測有誤，這兩個節點的結果在新指標下仍會被視為「假」。

實作細節：所有資料集的批次大小（batch size）皆設為 16，並搭配標籤平滑（label smoothing）與 AdamW 優化器進行訓練，學習率為 5e-5。實驗報告的結果皆為 5 次不同隨機種子的平均分數。所有實驗皆在單張 Tesla V100M32 GPU 上完成。此外，在解碼階段，先前已生成過的詞元也會從後續的動態詞表中排除。

3.2主要結果

3.3消融實驗

4相關工作

既有的 HTC 研究可歸為局部方法與全局方法兩類。局部方法傾向於建構多個局部分類器，通常忽略了分類體系的整體結構資訊。作為近年 HTC 研究的主流，全局方法使用單一模型處理所有類別，並引入各種策略捕捉標籤空間的階層資訊。例如：以階層式網路搭配改良版動態路由演算法來擷取概念並建模分享過程；HMC-Capsule 使用膠囊網路（capsule network）將文件分類到階層式標籤；HiLAP-RL 將 HTC 表述為馬可夫決策過程，透過深度強化學習學習標籤指派策略；HTCInfoMax 利用文本—標籤互資訊最大化演算法與標籤先驗匹配策略來捕捉標籤間的階層資訊；HiAGM 引入兩種結構編碼器（Tree-LSTM 與 GCN）以「由上而下」與「由下而上」兩種方式建模階層標籤；HiMatch 提出一個階層感知的標籤語意匹配網路，以階層感知方式學習文本—標籤語意匹配關係；HVHMC 則引入鬆耦合圖卷積神經網路作為表示元件，同時捕捉垂直與水平的類別依賴關係。儘管上述方法在一定程度上取得成功，但大多數仍受「標籤不一致」問題所困擾。

值得一提的是，先前有兩項工作同樣採用序列到序列（seq2seq）範式來處理 HTC 任務：其一是 SGM，其二是 Risch 等人（2020）的研究。然而，這兩項工作皆僅限於單路徑場景，無法處理多路徑情況；此外，由於這兩種方法在生成階層式標籤序列時是不受控制的，因此同樣會遭遇「標籤不一致」的問題。

5結論

本文提出 Seq2Tree 方法，用以解決既有 HTC 方法中「標籤不一致」的侷限。Seq2Tree 將 HTC 表述為序列生成問題，並採用以 T5 為基礎的 seq2seq 架構，為每份文件生成 DFS 風格的標籤序列。透過這種簡單卻有效的方式，Seq2Tree 能夠捕捉分類體系的結構資訊，並藉由帶動態詞表的受限解碼策略，確保生成標籤的一致性。三個基準資料集上的實驗結果，證實了 Seq2Tree 的有效性。
